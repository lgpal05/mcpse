Securing the MCP Server
The MCP server is the authoritative enforcement point. UI and orchestrator checks can be bypassed; every tool call must be validated here with a Bearer token and the correct OAuth scope.
=========

Add Authorization Imports
Wire in JWT validation and the FastMCP Bearer provider:

sed -i '/^from fastmcp import FastMCP/a\
\
import jwt\
from fastmcp.server.auth import BearerAuthProvider\
from auth import verify_token
' mcp_server.py

Add Token Verification Helpers
Add verify, scopes, and require_scope so each tool can validate the JWT and required scope before running:
===========
sed -i '/^# ── VULNERABLE: No auth provider/i\
\
def _verify(token: str):\
    """Return claims dict if the token is valid, None if not."""\
    try:\
        return verify_token(token)\
    except jwt.InvalidTokenError:\
        return None\
\
\
def _scopes(ctx) -> list[str]:\
    """Extract granted scopes from the request context."""\
    scope = (ctx or {}).get("auth_claims", {}).get("scope", "")\
    if isinstance(scope, str):\
        return scope.split()\
    return []\
\
\
def _require_scope(ctx, scope: str):\
    """Raise PermissionError if the token does not include the required scope."""\
    if scope not in _scopes(ctx):\
        raise PermissionError(\
            f"Required scope '"'"'{scope}'"'"' not granted. Have: {_scopes(ctx)}"\
        )\
' mcp_server.py


Enable BearerAuthProvider
Register verify with FastMCP so unauthenticated MCP requests receive 401:
=============
sed -i 's/^mcp = FastMCP("VULNERABLE MCP Server (NO AUTH)")/auth = BearerAuthProvider(verify_token=_verify)\
mcp = FastMCP("Protected MCP Server", auth=auth)/' mcp_server.py

Harden the Job Tools
Add a ctx parameter and require_scope to list_jobs, post_job, and delete_job (the tools the web app uses):
==========
sed -i 's/^def list_jobs() -> dict:/def list_jobs(ctx) -> dict:/' mcp_server.py
sed -i 's/# _require_scope(ctx, "jobs:read")  # COMMENTED OUT - NO AUTH CHECK!/_require_scope(ctx, "jobs:read")/' mcp_server.py
sed -i '/def list_jobs(ctx)/,/^@mcp.tool()/{
  /"warning": " NO AUTH/d
}' mcp_server.py

sed -i 's/^def post_job(title: str, company: str, location: str) -> dict:/def post_job(title: str, company: str, location: str, ctx) -> dict:/' mcp_server.py
sed -i 's/# _require_scope(ctx, "jobs:write")  # COMMENTED OUT - NO AUTH CHECK!/_require_scope(ctx, "jobs:write")\
    claims = ctx.get("auth_claims", {})/' mcp_server.py
sed -i 's/"posted_by": "UNKNOWN (no auth)"/"posted_by": claims.get("sub")/' mcp_server.py
sed -i '/"message": " Job posted WITHOUT auth check!",/d' mcp_server.py

sed -i 's/^def delete_job(job_id: int) -> dict:/def delete_job(job_id: int, ctx) -> dict:/' mcp_server.py
sed -i 's/# _require_scope(ctx, "jobs:delete")  # COMMENTED OUT - NO AUTH CHECK!/_require_scope(ctx, "jobs:delete")\
    claims = ctx.get("auth_claims", {})/' mcp_server.py
sed -i 's/"message": f"  Job {job_id} deleted WITHOUT auth check!",/"message": f"Job deleted by {claims.get('\''sub'\'')}",/' mcp_server.py
sed -i '/"warning": "This should NOT be possible for employee users!",/d' mcp_server.py
