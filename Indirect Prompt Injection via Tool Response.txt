Practical Defenses
===============
Apply these controls in combination:

Add response sanitization so forged control tokens like <|start_header_id|> and other instruction-like markers in tool output are stripped or quarantined before the model can use them for routing.
Add tool call policy checks that block high-impact follow-up actions unless user intent is explicit in the conversation.
Enforce human approval before any action that transmits sensitive records externally.
Apply least privilege tool design so analytics tools cannot directly invoke outbound reporting functions.
Maintain full tool-call logging and alert on suspicious chains like read-record followed by external dispatch.
