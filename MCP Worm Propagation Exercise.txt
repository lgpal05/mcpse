Creating the MCP Server
-------------
mkdir -p servers data
cat > servers/memo_server.py << 'EOF'
import json
import os
import fcntl
import tempfile
from datetime import date
from fastmcp import FastMCP

DEPARTMENT = os.environ.get("DEPARTMENT", "Unknown")
DATA_FILE  = os.environ.get("DATA_FILE", "/data/memos.json")
PORT       = int(os.environ.get("PORT", 8000))

mcp = FastMCP({"HR": "HRMemos", "Engineering": "EngineeringMemos"}.get(DEPARTMENT, DEPARTMENT.replace(" ", "") + "Memos"))


def _read_json() -> dict:
    with open(DATA_FILE, "r") as f:
        fcntl.flock(f, fcntl.LOCK_SH)
        data = json.load(f)
        fcntl.flock(f, fcntl.LOCK_UN)
    return data


def _write_json(data: dict) -> None:
    dir_name = os.path.dirname(DATA_FILE)
    with tempfile.NamedTemporaryFile(
        mode="w", dir=dir_name, delete=False, suffix=".tmp"
    ) as tmp:
        fcntl.flock(tmp, fcntl.LOCK_EX)
        json.dump(data, tmp, indent=2)
        fcntl.flock(tmp, fcntl.LOCK_UN)
        tmp_path = tmp.name
    os.replace(tmp_path, DATA_FILE)


@mcp.tool()
def read_memos() -> str:
    """Read all memos from the department memo board."""
    data = _read_json()
    memos = data.get("memos", [])

    if not memos:
        return f"{DEPARTMENT} Department Memos:\n(No memos yet)"

    lines = [f"{DEPARTMENT} Department Memos:"]
    for memo in memos:
        lines.append(f"[{memo['date']}] {memo['author']}: {memo['text']}")

    return "\n".join(lines)


@mcp.tool()
def post_memo(author: str, text: str) -> str:
    """Post a new memo to the department memo board.

    Args:
        author: Name of the person posting the memo.
        text:   Content of the memo.
    """
    data = _read_json()
    memos = data.get("memos", [])

    next_id = max((m["id"] for m in memos), default=0) + 1

    memos.append({
        "id":     next_id,
        "author": author,
        "date":   date.today().isoformat(),
        "text":   text,
    })

    data["memos"] = memos
    _write_json(data)

    return f"Memo posted to {DEPARTMENT} board successfully."


if __name__ == "__main__":
    mcp.run(transport="sse", host="0.0.0.0", port=PORT)
EOF


Understanding the Server Code
==============
The server exposes exactly two tools: read_memos and post_memo.

read_memos reads the department JSON file and returns all memos as a formatted list. post_memo accepts an author name and text content, then appends a new entry to the file.

File locking with the fcntl library prevents corruption when multiple requests arrive at the same time.\

Creating the Dockerfile
============

FROM python:3.11-slim
WORKDIR /app
RUN pip install fastmcp==2.3.2 uvicorn==0.49.0
COPY memo_server.py .
CMD ["python", "memo_server.py"]
EOF

The Payload
The worm payload is designed around the phrase COMPLIANCE POLICY SEC-2026-047. When the model reads any memo containing that exact phrase during a read_memos call, the custom instructions force it to call post_memo on the other board before responding to the user.

The payload is written to look like a legitimate corporate policy update. Nothing in its appearance signals that it is malicious.
